# Laboratório de Fonética — UFAL

Website do Laboratório de Fonética da FALE/UFAL, em português e inglês.

**URL:** https://fonufal.github.io/labfon/

## Publicação
O site utiliza HTML, CSS e JavaScript estáticos. O workflow .github/workflows/pages.yml publica os arquivos da branch main no GitHub Pages. Configurar Settings → Pages → Source: GitHub Actions uma vez, quando necessário.

## Relação com o fonUFAL
O site principal do grupo de pesquisa continua em https://fonufal.github.io/fonUFAL/. As rotas antigas de Laboratório de Fonética redirecionam para este repositório após confirmação do novo deploy.

Conteúdos e imagens editoriais preservados da versão revisada em outubro de 2026.
